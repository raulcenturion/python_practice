# Lecciones de lógica

Challenges y ejercicios de razonamiento en Python (conteo, filtros, lookups, dicts, simulación).

## Cómo correr

Desde la raíz del repo (`welcomePy`):

```bash
.venv/bin/python Lecciones/logica/01_challenge_four_fantastic/teoria.py
.venv/bin/python Lecciones/logica/01_challenge_four_fantastic/practica.py
```

Mismo patrón para el resto:

```bash
.venv/bin/python Lecciones/logica/02_challenge_jurassic_park/teoria.py
.venv/bin/python Lecciones/logica/03_challenge_find_first_sum/teoria.py
.venv/bin/python Lecciones/logica/04_dictionaries/teoria.py
.venv/bin/python Lecciones/logica/05_challenge_battle/teoria.py
```

También sirve `python3` si tu entorno ya tiene lo necesario.

## Lecciones

| Carpeta | Tema |
|---------|------|
| `01_challenge_four_fantastic` | Contar R/J (case-insensitive) y equilibrio |
| `02_challenge_jurassic_park` | Suma de pares en una lista |
| `03_challenge_find_first_sum` | Primer par que suma `goal` (dict O(n)) |
| `04_dictionaries` | CRUD, anidados, `pop` / `update` / `items` |
| `05_challenge_battle` | Duelo con carry entre rondas → `"Xa"` / `"Xb"` / `"x"` |

## Flujo sugerido

1. Leé y ejecutá `teoria.py` (demos + resumen).
2. Resolvé `practica.py` (stubs con `NotImplementedError` hasta que completes).
