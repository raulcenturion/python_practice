# Prácticas extra

Cada lección que ya estaba tiene dos archivos nuevos:

- `ejercicios.md` explica el tema, enlaza la documentación y deja el enunciado con un ejemplo.
- `practica_extra.py` es lo que se completa. Al correrlo sale el menú en la terminal y `input()` pide el número. Imprime el enunciado y si el ejemplo quedó `ok`, `Pendiente` o `Revisar`. Después pregunta si querés probar con tus datos.

Los enunciados son de este repo. [LeetCode Explore](https://leetcode.com/explore/) y [Coding Challenges](https://coding-challenges.dev/problems) sirven para seguir después, con los problemas de ellos.

Un ejercicio solo: `./r 07 practica_extra 2`. Sin número, el menú. Otras áreas: `./r logica/01 practica_extra 1`. Integradores: `./r Lecciones/integradores/01_agenda_contactos/practica_extra.py 1`.

El banco en FastAPI está en [`fastApi/practicas/BANCO.md`](../fastApi/practicas/BANCO.md).
